See in which snapshots a package is available, and when its package file changed.

Under development. This page shows which snapshots contain a package, and when its .pkg file differs from the previous snapshot. It does not yet show version history: that has to be parsed from every historical snapshot, which has not been done. Because a changed file only tells us that something changed, a later version of this page is planned to let you browse by the labeled version recorded inside each .pkg file.
